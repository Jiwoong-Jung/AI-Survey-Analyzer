# AI 강의평가 인사이트 — 웹 버전 2.1.0

문항과 응답이 함께 있는 **엑셀(XLSX) 한 파일**로 분석하고 A4 PDF로 저장하는 정적 웹 도구입니다. **TXT는 필수가 아닌 원본 문항 대조용**입니다. 발표자: **정지웅** / 경기인력개발원 훈련취업팀.

**이 버전은 외부 생성형 AI를 호출하지 않습니다.** 주제 사전과 감정 표현 규칙에 따른 분석 및 피드백 초안 작성입니다. 사전에 없는 주제, 반어, 복잡한 부정 표현은 놓치거나 잘못 판단할 수 있습니다. 수량 충족은 정확도 또는 AI 경진대회 점수를 보증하는 표시가 아닙니다.

## 먼저 테스트하기

1. 압축을 풀고 안에 있는 파일 전체를 GitHub 저장소의 게시 폴더에 올립니다. 기존 `index.html`, `style.css`, `app.js`도 교체합니다. **세 파일만 교체하면 안 됩니다.** 새로 추가된 `analysis.js`, `xlsx-reader.js`, `pdf-report.js`, `demo.js`도 필요합니다.
2. `Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save`로 설정합니다. 이미 다른 브랜치를 게시하고 있다면 해당 브랜치에 올립니다. `index.html`은 선택한 게시 폴더의 최상단에 있어야 합니다.
3. 배포가 완료되면 웹주소로 접속하고 **가상 자료로 시연**을 누릅니다.
4. 결과를 확인하고 **PDF 미리보기**로 이동합니다. 하단의 검토 확인란에 체크한 후 **PDF 보고서 다운로드**를 누릅니다.
5. 실제 분석은 가상 시연을 초기화한 뒤, 문항과 응답이 포함된 XLSX만 웹화면에서 선택합니다. TXT는 `추가 설정 — 원본 문항 TXT 대조 (선택)`에서 필요한 경우에만 선택합니다. 실제 응답 파일을 저장소에 올리는 것이 아닙니다.

GitHub 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
게시 파일 위치: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 결과물

**키워드:** 주제 사전으로 유사 표현을 묶고 빈도 상위 10개를 표시합니다. 빈도는 해당 주제를 포함한 의견 셀 수입니다. 같은 셀에서 여러 번 언급해도 1건이며 서로 다른 주제는 중복 집계됩니다. 의미와 근거 의견 번호가 함께 표시됩니다.

**의견:** 내용 있는 의견 셀 전체를 긍정, 중립, 부정 중 하나로 임시 분류합니다. 혼합 의견과 판단이 어려운 의견은 검토 표시가 붙습니다. 담당자가 분류를 수정하면 주요 사유, 개선안, 아직 수정하지 않은 피드백을 함께 갱신합니다. 범주별 사유는 최대 5개입니다.

**개선안:** 서술형 근거와 점수가 낮은 문항을 우선 사용해 최대 5개를 제안합니다. 긍정 근거를 사용하는 항목은 ‘유지·강화 제안’으로 분리합니다. 조치의 시행이 확정됐다는 뜻은 아닙니다.

**개인별 피드백:** 원자료의 의견을 인용하고 관련 주제를 반영한 익명 응답별 검토용 초안을 작성합니다. 의견이 있는 교육생의 응답 순서대로 10명을 기본 선택합니다. 선택 대상과 문구를 수정할 수 있습니다. 의견이 없는 교육생에게는 성향이나 경험을 추정한 메시지를 만들지 않습니다. 익명 ID는 분석 대상으로 남은 행의 순서이며 영구 ID가 아닙니다. 무기명 설문의 실제 응답자를 추적하는 기능은 없습니다.

**근거가 부족하면:** 10개, 5개, 10명을 맞추기 위해 원문에 없는 내용을 만들지 않습니다. 확인 수량과 부족 상태를 표시합니다. 일부 결과가 기준에 미달하면 자료 보완 또는 담당자 검토가 필요합니다.

## 점수와 미응답 처리

- 기본 5점: 숫자 1~5 또는 ‘매우 그렇지 않다 / 그렇지 않다 / 보통이다 / 그렇다 / 매우 그렇다’ 등 지원하는 5점 문구.
- 7점 선택: 숫자 1~7만 인정합니다. 5점 문구를 7점으로 변환하지 않습니다.
- 빈칸, 실제 숫자 0, 해당 없음, 기타 무효값을 각각 집계하며 모두 평균에서 제외합니다.
- 전체 평균은 모든 유효 점수의 합을 유효 점수 개수로 나눈 값입니다. 문항별 평균을 단순 평균하지 않습니다.
- 정량 및 서술형으로 선택된 열이 전부 비어 있는 행은 분석 대상에서 제외하고 제외 행 수를 표시합니다. 이름만 있다고 응답자로 세지 않습니다.
- ‘없음’, ‘0’ 등 내용 없는 서술형 응답을 중립 의견으로 집계하지 않습니다. ‘좋아요’처럼 짧지만 의미 있는 응답은 포함합니다.
- XLSX 내부의 `<v>0</v>`는 셀 유형이 공유 문자열이면 문자열 목록의 0번 항목을 뜻할 수 있습니다. 읽기 코드는 셀 유형을 확인하여, 빈 문자열을 실제 점수 0으로 오인하지 않습니다.

## 문항과 파일 설정

문항과 응답은 항상 **엑셀에서 읽습니다.** `문항 인식과 익명화 설정`에서 시트, 문항명 행, 열 용도와 추가 가림 단어를 확인하세요. 이름과 제출일시는 분석 제외, 점수는 정량 점수, 자유의견은 서술형 의견으로 지정합니다.

TXT를 선택하지 않으면 화면과 PDF에 **‘엑셀 문항 사용 / TXT 대조 생략’**으로 표시합니다. 미선택을 오류나 불일치로 취급하지 않습니다.

원본 문항 대조가 필요할 때만 **‘추가 설정 — 원본 문항 TXT 대조 (선택)’**을 펼쳐 TXT를 선택하세요. `TXT 선택 해제`로 엑셀 단독 분석으로 돌아갈 수 있습니다. TXT를 추가하거나 해제하면 이전 분석 결과는 비워지지만, 선택한 엑셀 시트와 문항명 행 및 열 용도는 유지됩니다. 다시 분석한 뒤 검토하세요. TXT 인코딩은 UTF-8 우선 자동 감지하며 EUC-KR도 선택 가능합니다. 빈 파일이나 인코딩 오류가 있는 TXT는 해제하고 오류를 안내합니다.

**TXT는 대조만 수행하며 점수 계산이나 열 용도, 엑셀 문항명을 자동으로 바꾸지 않습니다.** Q1, Q2처럼 번호만 있거나 비어 있거나 중복되는 분석 문항명은 경고합니다. 원본 엑셀에 전체 문항 내용을 보완하고 다시 선택하세요. TXT를 문항 순서에 따라 강제로 연결하지 않습니다.

파일, 입력 정보, 문항 설정을 바꾸면 이전 분석과 수정 메시지가 초기화됩니다. 보관이 필요하면 먼저 PDF를 저장하세요.

지원 범위: 암호가 없는 일반 `.xlsx`, 파일 10MB 이하, 워크시트 3,002행 및 200열 이하, 읽는 셀 250,000개 이하, 셀당 10,000자 이하. TXT는 1MB 이하입니다. 첫 번째 표시 시트를 기본 선택하며 여러 시트를 자동 합산하지 않습니다. 수식은 실행하거나 재계산하지 않고 저장된 결과만 읽습니다. 저장 결과가 없으면 경고합니다. `.xls`, `.xlsm`, `.xlsb`, 암호화 파일, ZIP64는 지원하지 않습니다.

최신 Chrome 또는 Edge에서 먼저 테스트하세요. 압축 해제에 브라우저의 `DecompressionStream('deflate-raw')`를 사용하며 지원되지 않으면 안내 오류를 표시합니다.
API 문서: https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream/DecompressionStream

## PDF

A4 규격, 한글 표시, 자동 페이지 나눔, 표 머리글 반복, 페이지 번호를 적용합니다. 개선안과 짧은 개인별 피드백은 가능한 한 제목과 본문을 같은 페이지에 둡니다. PDF 생성 시 화면의 분석 결과를 복사해서 사용하며 다시 분석하지 않습니다. 개인별 메시지를 수정하면 PDF에도 반영됩니다. 전체 의견 부록은 기본 제외이며 사용자가 선택할 수 있습니다.

**한글 글꼴 파일을 별도로 배포하지 않기 위해 브라우저에서 글자를 그린 이미지형 PDF입니다.** 텍스트 검색, 선택과 복사, 스크린리더 접근성이 제한되고 출력 파일 크기가 커질 수 있습니다. PC에 한글 글꼴이 설치되어 있어야 합니다. PDF가 100쪽을 넘으면 부록이나 선택 피드백 수를 줄이도록 안내합니다. 미리보기는 같은 내용을 보여주는 HTML 미리보기이며 PDF와 화면상의 줄바꿈은 다를 수 있습니다.

## 개인정보와 운영 유의사항

교수자 호칭 및 교육생 이름 열에서 확인한 이름, 추가 입력한 단어, 일부 이메일, 전화번호, 식별번호와 개인 건강에 관한 단정 표현을 가립니다. 자동 탐지가 완전하지 않으므로 **공유 전에 반드시 직접 확인**하세요. 이름이 없는 평문에서 등장하는 모든 사람이나 주소를 자동 식별하는 도구는 아닙니다. 개선 조치나 참여자 성향을 확인된 사실처럼 판단하지 않습니다.

원본 파일, 실명 대응표, 분석 결과를 서버나 로컬 저장소에 자동 저장하지 않습니다. API 키, 쿠키, 분석 추적 코드, 외부 CDN이 없으며 `connect-src 'none'` 정책으로 웹 통신을 제한합니다. 이미 내려받은 PDF는 초기화 버튼으로 삭제되지 않습니다. 브라우저 확장 프로그램, PC 보안, GitHub 자체 접속 로그는 이 코드가 통제하지 않습니다.

실제 이름이나 의견이 있는 자료를 GitHub에 올리지 마세요. 이 압축의 샘플은 새로 만든 가상 자료이며 사용자가 업로드한 실제 응답 파일은 포함하지 않았습니다. `.gitignore`는 보조 장치일 뿐, 웹에서 직접 업로드하거나 이미 추적 중인 파일까지 보호하는 보안 장치가 아닙니다.

## 수정 후 테스트

`node tests/analysis.test.cjs`로 핵심 분석 규칙을 점검할 수 있습니다. 웹 사용에는 Node.js가 필요하지 않습니다. 파일 또는 분석 설정을 바꾸면 이전 결과를 비우므로 다시 분석해야 합니다. 새 코드가 보이지 않으면 배포 완료 여부와 실제 게시 폴더를 확인하고 페이지를 새로고침하세요.

## v2.1.0 변경 사항
- XLSX 1개를 기본 입력으로 변경하고 TXT 필수 조건 제거
- TXT 입력을 접힌 선택 설정으로 이동, 선택 해제 버튼 추가
- TXT 유무를 화면/PDF에 명확하게 표시, 미선택 불일치 경고 제거
- TXT 추가/해제 시 시트/문항명 행/열 용도를 유지하고 결과는 재분석
- 문항 번호만 있는 제목, 빈 제목, 중복 제목 경고
- 자동 분류가 불가능한 열도 설정 화면에서 용도를 직접 지정할 수 있도록 수정
- 기관 로고 클릭 시 경기인력개발원 홈페이지 새 탭 열기 유지
- 발표자 정지웅, 버전 2.1.0 표기 및 캐시 구분값 반영

기능과 화면은 동봉한 코드 기준입니다. GitHub에 파일을 교체하기 전까지 기존 사이트는 자동으로 변경되지 않습니다.
